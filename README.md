این اسکریپت یک ابزار جامع برای مدیریت سرور WireGuard VPN است که با هدف ساده‌سازی نصب، پیکربندی و مدیریت کلاینت‌های WireGuard طراحی شده است. این اسکریپت شامل قابلیت‌های پیشرفته‌ای مانند مدیریت کاربران، اعمال محدودیت‌های حجمی و زمانی، ایجاد رابط کاربری وب با پشتیبانی از QR Code و بهینه‌سازی عملکرد سرور است. در ادامه، توضیحات کامل و جامعی در مورد این اسکریپت ارائه شده است تا برای قرار دادن در GitHub مناسب باشد.

WireGuard Manager v6.1.0
WireGuard Manager یک اسکریپت Bash است که برای نصب، پیکربندی و مدیریت سرور WireGuard در سیستم‌های مبتنی بر لینوکس (مانند Ubuntu، Debian، CentOS، RHEL و غیره) طراحی شده است. این اسکریپت قابلیت‌های متعددی از جمله نصب خودکار، مدیریت کلاینت‌ها، اعمال محدودیت‌های داده و زمان، و ارائه یک رابط کاربری وب با امکان نمایش QR Code برای اتصال آسان کلاینت‌ها را فراهم می‌کند.
ویژگی‌ها

نصب خودکار: نصب و پیکربندی کامل WireGuard و وابستگی‌های آن.
مدیریت کلاینت‌ها: افزودن، حذف و لیست کردن کلاینت‌ها با اطلاعات جامع.
مدیریت محدودیت‌ها: تنظیم محدودیت‌های حجمی (Quota) و تاریخ انقضا برای هر کلاینت.
رابط کاربری وب: یک پنل وب زیبا و کاربردی برای نمایش اطلاعات کلاینت (مانند مصرف داده، محدودیت، تاریخ انقضا) و QR Code برای اتصال آسان.
پشتیبانی از QR Code: تولید QR Code برای فایل‌های پیکربندی کلاینت‌ها جهت اسکن آسان با اپلیکیشن‌های WireGuard.
پشتیبانی از سیستم‌های مختلف: سازگار با توزیع‌های مختلف لینوکس (Ubuntu، Debian، CentOS، RHEL، Rocky، AlmaLinux، Fedora).
بهینه‌سازی عملکرد: اعمال تنظیمات سیستمی برای بهبود عملکرد WireGuard.
فایروال: پیکربندی خودکار فایروال (UFW یا firewalld) برای باز کردن پورت‌های مورد نیاز.


ساختار اسکریپت
اسکریپت به صورت مدولار طراحی شده و شامل بخش‌های زیر است:

تنظیمات اولیه و متغیرها:

تعریف رنگ‌ها برای خروجی ترمینال (RED، GREEN، YELLOW، و غیره).
متغیرهای جهانی مانند مسیرهای فایل‌ها (/etc/wireguard)، نام رابط شبکه (wg0)، پورت پیش‌فرض (1010)، زیرشبکه (10.0.0.0/24) و MTU (1420).


توابع کمکی:

need_root: بررسی دسترسی root.
detect_os: شناسایی سیستم‌عامل و نسخه آن.
pkg_install: نصب بسته‌ها با توجه به نوع سیستم‌عامل.
update_system: به‌روزرسانی سیستم.
public_ip: دریافت آدرس IP عمومی سرور.
next_client_ip: تخصیص IP جدید برای کلاینت‌ها.
bytes_to_gb: تبدیل بایت به گیگابایت.
generate_qr_base64: تولید QR Code به صورت base64.


نصب و پیکربندی WireGuard:

نصب بسته‌های مورد نیاز (مانند wireguard-tools, qrencode, nginx, php-fpm).
فعال‌سازی IP Forwarding.
تولید کلیدهای خصوصی و عمومی سرور.
ایجاد فایل پیکربندی سرور (wg0.conf) با تنظیمات NAT و فورواردینگ.


مدیریت فایروال:

پشتیبانی از ufw و firewalld برای باز کردن پورت‌های مورد نیاز (پورت WireGuard و SSH).
در صورت عدم وجود فایروال، استفاده از قوانین iptables تعریف‌شده در فایل پیکربندی.


مدیریت پایگاه داده:

ایجاد دو پایگاه داده ساده (متن‌بنیاد):

clients.db: ذخیره اطلاعات کلاینت‌ها (نام، کلید خصوصی، کلید عمومی، آدرس IP، تاریخ ایجاد).
quota.db: ذخیره اطلاعات محدودیت‌ها (مصرف داده، سقف داده، تاریخ انقضا، وضعیت فعال بودن).


توابعی برای مدیریت محدودیت‌ها (quota_set, quota_get_line).


مدیریت کلاینت‌ها:

add_client: افزودن کلاینت جدید با تولید کلید، تخصیص IP، ایجاد فایل پیکربندی و QR Code.
remove_client: حذف کلاینت و اطلاعات مرتبط از پایگاه داده و فایل‌های پیکربندی.
list_clients: نمایش لیست کلاینت‌ها با اطلاعات مصرف داده، محدودیت، و روزهای باقی‌مانده.


کنترل سرویس:

enable_start: فعال‌سازی و راه‌اندازی سرویس WireGuard (wg-quick@wg0).


رابط کاربری وب:

نصب و پیکربندی Nginx و PHP-FPM.
ایجاد یک فایل PHP (index.php) برای نمایش اطلاعات کلاینت و QR Code.
اسکریپت‌های کمکی (wg-client-info, wg-generate-qr) برای تعامل با پایگاه داده و تولید QR Code.
تنظیم دسترسی‌های sudo برای اجرای امن اسکریپت‌ها توسط کاربر وب (www-data).


بهینه‌سازی عملکرد:

اعمال تنظیمات sysctl برای بهبود عملکرد شبکه (مانند افزایش بافرها و استفاده از الگوریتم BBR).


مدیریت دستورات:

پشتیبانی از دستورات مختلف از طریق خط فرمان:

install: نصب کامل.
add-client: افزودن کلاینت.
remove-client: حذف کلاینت.
set-quota: تنظیم محدودیت داده.
list-clients: نمایش لیست کلاینت‌ها.
status: نمایش وضعیت WireGuard.
web: نصب/به‌روزرسانی پنل وب.
help: نمایش راهنما.






نحوه استفاده
پیش‌نیازها

دسترسی root به سرور.
سیستم‌عامل لینوکس (Ubuntu, Debian, CentOS, RHEL, Rocky, AlmaLinux, Fedora).
اتصال به اینترنت برای دانلود بسته‌ها و دریافت آدرس IP عمومی.

نصب و راه‌اندازی

فایل اسکریپت را دانلود کنید:
bashwget wget https://raw.githubusercontent.com/3aeidkhalili/wireguard-manager/install.sh

فایل را اجرایی کنید:
bashchmod +x install.sh

دستور نصب را اجرا کنید:
bashsudo ./install.sh install


دستورات موجود
bash./install.sh install                       # نصب و پیکربندی کامل WireGuard
./install.sh add-client john 5 30         # افزودن کلاینت با 5 گیگابایت محدودیت برای 30 روز
./install.sh add-client jane 0 90         # افزودن کلاینت با داده نامحدود برای 90 روز
./install.sh remove-client john           # حذف کلاینت
./install.sh set-quota john 10 60         # تنظیم محدودیت 10 گیگابایت برای 60 روز
./install.sh list-clients                 # نمایش لیست کلاینت‌ها
./install.sh status                       # نمایش وضعیت WireGuard
./install.sh web                          # نصب/به‌روزرسانی پنل وب
./install.sh help                         # نمایش راهنما
دسترسی به پنل وب
پس از نصب، پنل وب در آدرس زیر قابل دسترسی است:
texthttp://<SERVER_IP>/
کاربران می‌توانند با وارد کردن کلید خصوصی خود، اطلاعات اتصال (مانند مصرف داده، محدودیت، تاریخ انقضا) و QR Code را مشاهده کنند.

ساختار فایل‌ها و دایرکتوری‌ها

/etc/wireguard/wg0.conf: فایل پیکربندی سرور WireGuard.
/etc/wireguard/server_private.key: کلید خصوصی سرور.
/etc/wireguard/server_public.key: کلید عمومی سرور.
/etc/wireguard/clients.db: پایگاه داده کلاینت‌ها.
/etc/wireguard/quota.db: پایگاه داده محدودیت‌ها.
/etc/wireguard/clients/: دایرکتوری ذخیره فایل‌های پیکربندی و کلیدهای کلاینت‌ها.
/var/www/wireguard/: دایرکتوری پنل وب.
/usr/local/bin/wg-client-info: اسکریپت کمکی برای اطلاعات کلاینت.
/usr/local/bin/wg-generate-qr: اسکریپت کمکی برای تولید QR Code.


نکات مهم

امنیت: اسکریپت از umask 077 برای تنظیم مجوزهای امن فایل‌های کلید استفاده می‌کند. همچنین، دسترسی‌های sudo برای پنل وب محدود شده است.
پشتیبانی از فایروال: اسکریپت به‌طور خودکار فایروال (UFW یا firewalld) را پیکربندی می‌کند، اما در صورت عدم وجود فایروال، از قوانین iptables استفاده می‌کند.
پشتیبانی از QR Code: برای تولید QR Code، بسته qrencode مورد نیاز است.
زبان پنل وب: رابط کاربری وب به زبان فارسی و با جهت راست‌به‌چپ (RTL) طراحی شده است.


نصب وابستگی‌ها
اسکریپت به‌طور خودکار بسته‌های زیر را نصب می‌کند:

wireguard-tools: ابزارهای WireGuard.
qrencode: برای تولید QR Code.
nginx: وب‌سرور برای پنل وب.
php-fpm, php-cli, php-curl, php-gd: برای اجرای پنل وب.
bc, jq, curl: ابزارهای کمکی.


بهینه‌سازی‌ها

IP Forwarding: فعال‌سازی فورواردینگ IP برای پشتیبانی از NAT.
Performance Tweaks: تنظیمات sysctl برای افزایش بافرهای شبکه و استفاده از الگوریتم TCP BBR.
فایروال: باز کردن پورت‌های مورد نیاز (پورت WireGuard و 80 برای وب).


محدودیت‌ها و نکات توسعه

مدیریت داده مصرفی: در حال حاضر، مصرف داده به‌صورت دستی در quota.db ثبت می‌شود. برای ردیابی خودکار مصرف، نیاز به ابزارهای اضافی مانند vnstat است.
پشتیبانی از IPv6: اسکریپت از IPv6 پشتیبانی می‌کند، اما نیاز به بررسی دقیق‌تر در محیط‌های IPv6-only دارد.
امنیت وب: پنل وب از کلید خصوصی برای شناسایی کاربران استفاده می‌کند. برای امنیت بیشتر، می‌توان احراز هویت پیشرفته‌تر (مانند رمز عبور) اضافه کرد.
